# Kanban Board

Lightweight kanban board with To Do / Doing / Done columns.

## Features
- Add cards to any column
- Move cards left/right
- Edit title & notes
- localStorage persistence

## Limitations
- No multiplayer / realtime
- No file attachments

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```

## Honesty notes
- Portfolio mini-app showcase
- Not multi-tenant SaaS
